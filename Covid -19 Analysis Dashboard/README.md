This project is an interactive COVID-19 India Dashboard created using Tableau to analyze and visualize the impact of COVID-19 across different states and zones in India. The dashboard provides key performance indicators such as Total Cases, Active Cases, Discharged Cases, Deaths, Average Discharge Ratio, and Average Death Ratio. It includes visualizations for COVID-19 cases by zone, state-wise recovery rates, the top 10 states by cases, population vs. total cases, and the distribution of active, recovered, and deceased cases. An interactive India map is also used to provide a geographical view of the spread of COVID-19. The project demonstrates the use of Tableau for data visualization, interactive dashboards, KPI analysis, geographical mapping, and extracting meaningful insights from healthcare data.
